Construcción del Casco Iron Man

1. Modelado 3D

El casco fue diseñado digitalmente en software 3D para obtener cada pieza con las proporciones correctas y listas para impresión.

2. Impresión y ensamblado

Las piezas fueron impresas en 3D por partes y luego ensambladas utilizando adhesivo resistente para formar el casco completo.

3. Lijado y detalles

Se aplicó masilla, se lijaron imperfecciones y se corrigió la superficie hasta dejarla lista para pintar.

4. Pintura y acabado

Se aplicó primer, pintura metálica roja y dorada, y barniz protector para conseguir el acabado clásico del casco de Iron Man.

5. Instalación del hardware

Se añadieron servomotores, luces LED y un microcontrolador para permitir movimiento automático y encendido de ojos.

6. Resultado final

El casco final cuenta con apertura automática, iluminación interna y acabado cinematográfico.
